# Scanner

Scanner is a real-time mobile spatial reconstruction project for progressively building, inspecting, correcting, and refining 3D models from camera, motion, depth/LiDAR, ranging, and user-guided observations.

The project is intentionally multi-device and confidence-aware. A scan session can use one active scanner plus cooperating phones or spatial anchors, lock stable structural surfaces such as walls and floors, guide the user toward measurements that reduce uncertainty, and progressively refine geometry, texture, lighting, and material estimates.

Development is bootstrapping. See the architecture and roadmap added in the initial scaffold PR.
